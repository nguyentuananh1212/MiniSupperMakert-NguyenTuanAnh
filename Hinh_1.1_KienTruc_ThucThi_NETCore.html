📌 HƯỚNG DẪN DÁN VÀO ĐỒ ÁN:
1. Bạn dùng phím tắt Windows + Shift + S trên bàn phím để chụp khung sơ đồ bên dưới.
2. Mở file Word đồ án của bạn, đặt con trỏ tại ô [Hình 1.1] và bấm Ctrl + V để dán ảnh vào.
3. Hoặc: Trong Word, chọn Insert ➔ Pictures ➔ This Device rồi chọn file Hinh_1.1_KienTruc_ThucThi_NETCore.svg trong thư mục dự án để chèn trực tiếp dạng vector siêu nét!
Hình 1.1: Mô hình kiến trúc thực thi mã nguồn .NET Core (CIL, CLR và JIT Compiler)
